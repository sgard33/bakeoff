# Brand voice (short)

- Clear, confident, short sentences. No clever taglines on commercial pages.
- Prefer “Simple, transparent pricing.”
- Pro is the recommended plan — make it visually primary.

## Reuse, don’t reinvent

- Colors / type / radii: `tokens/brand.css`
- Buttons: `components/button-snippets.html`
- Cards / tiers: `components/card-snippets.html`
- Toggle: `components/toggle-snippets.html`

Accent teal (`--color-accent`) is for CTAs, the popular badge, and the featured tier only.
