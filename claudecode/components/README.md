# Component snippets

HTML fragments that define the **class vocabulary** for marketing UI:

- `button-snippets.html` → `btn`, `btn--primary`, `cta`
- `card-snippets.html` → `card`, `pricing-card`, `tier-*`, `badge`
- `toggle-snippets.html` → `billing-toggle`, accessible annual switch

Copy patterns into `index.html` / `style.css`; do not iframe these files.
